# Style brief: symbol-led minimal styles (B-009)

_2026-11-03. Explorer page: https://claude.ai/artifact/VBJkjxUQA5whAuAdPvtEx8 (source `drafts/estilos/`)._

## The ask (Mario, 2026-11-03, after feedback)

- Choose a **new design style** to replace the current Bosque/Claridad mix (D-016).
- **Minimalist colour palette.**
- **Symbols as decoration** across the page, using a shared symbol set. References: a solid Om glyph,
  a flat two-tone lotus + seated-figure emblem, and a monoline wellness icon set (iStock, Rudzhan Nagiev).
- **No people in yoga poses**, except the seated lotus position. The lotus flower is allowed.
- Only include styles that **already use this kind of imagery**. Leave out styles that don't.

## Symbol set

Every symbol maps to something on the page. Nothing is decoration only.

| Seated lotus figure | Yin yoga (the only human figure allowed) |
| Lotus | Desarrollo personal / Crecimiento personal; plan cards (1, 3 or 6 petals = activities in the plan) |
| Yin-yang | Bienestar emocional |
| Sun | Enfoque y energía |
| Stones (stacked) | Bienestar físico |
| Balance scale | Bienestar financiero (benefit and workshop) |
| Breath lines | Breathwork |
| Singing bowl | Sound healing |
| Snowflake | Inmersión en hielo |
| Spiral | Salud mental y arteterapia |
| Ensō | Mindfulness y presencia |
| Moon / moon phases | The four steps (waxing to full) in Noche celeste |
| Star, flower of life | Section dividers only |
| Mortar & herbs | Bienestar físico (Raíz ayurvédica only) |
| Om | Hero only, Raíz ayurvédica only, pending Carolyn |

**Excluded:** the tree-pose figure with arrows and any other asana silhouette. Third eye and hamsa are
in the reference set but read as esoteric to an HR buyer, so no style uses them. Om is sacred in
Hinduism, Buddhism and Jainism. Use it once, large and upright. Never use it as a bullet or pattern,
cropped or rotated.

## The six styles

All six previews use the same sections, copy and WhatsApp links as `drafts/borrador-1/`, with
Por qué and Quiénes somos left out. Activity cards show symbols in place of the AI-looking photos (B-008).

| # | Style | Where it comes from | Palette | Type | Symbol treatment | Good for HR | Risk |
|---|---|---|---|---|---|---|---|
| 1 | **Línea serena** | Monoline wellness icon sets (reference 3) | Papel #F8F8F5 · Grafito #2E3532 · Bosque #2C4A2E · Salvia #ECEEE8 | Jost Light / Source Sans 3 | One 1.35 px stroke family; large line drawing in hero | Most corporate; icons help scanning; keeps brand green | Looks stock if icons are generic |

Accent colours with low contrast (saffron, turmeric, turquoise) are used only in symbols, never for text.

## Styles left out

None of these uses this imagery natively:

- **Glassmorphism and soft 3D icons.** The current icon trend, but built on depth and gradients, not symbols.
- **Neo-brutalism.** Loud colour and heavy borders, no symbol tradition.
- **Organic blobs and gradients.** Abstract; symbols would be bolted on.
- **Swiss / editorial grid.** Clear, but built on type and photos.

## Recommendation

Start from **Línea serena**, and borrow the moon-phase steps from Noche celeste and the petal-count
lotus on the plan cards. Keep Om off the site until Carolyn approves it (new question Q-15).
